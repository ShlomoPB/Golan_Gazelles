## 1. Separate-Class Spatial Models

**Scientific question:** Do fawns, adult females, and adult males show different spatial responses to wolf and jackal gradients?

| Field | Authoritative specification |
|---|---|
| Status | **PRIMARY** |
| Input | Three 60 x 7 count histories, `SiteCovs_060324.csv`, `ObsCovs_050524.csv` |
| Framework | `spAbundance::NMix`, negative binomial, one model per class |
| Abundance formula | `~ Null.Wolf.Abundance.z * null.jackal.abundance.z` |
| Detection formula | `~ log_days_operational.z + cattle_sightings.z` |
| MCMC | 2,000 batches x 25; burn-in 5,000; thin 10; 3 chains; seed 20260623 |
| Script | `analyze_wolf_jackal_interaction_nmix.R` |
| Saved object | `publication_wolf_jackal_interaction_nmix_spabundance_fits.rds` |
| Tables | `publication_primary_spabundance_coefficients.csv`; `publication_spabundance_wolf_jackal_relative_conditional_effect_ratios.csv`; `publication_wolf_jackal_interaction_nmix_spabundance_diagnostics.csv` |
| Main figure | `publication_spabundance_wolf_jackal_relative_interaction_curves.png` and `.pdf`, generated by `make_spabundance_relative_wolf_jackal_figure.R` |
| SI figure | `publication_spabundance_wolf_jackal_relative_heatmap.png` and `.pdf` |
| Manuscript placement | Primary spatial Methods and Results |
| SI placement | Full coefficient, conditional-effect, and MCMC diagnostic tables |
| Limitations | Abundance and detection intercepts did not converge. Infer only relative predator gradients; do not report absolute abundance from these fits. Closure and repeated-individual assumptions remain important. |

The interaction figures are generated from posterior draws and omit the nonconverged intercept.

## 4. Residual Correlation Among Classes

**Scientific question:** Do demographic classes retain shared spatial structure after measured gradients are considered?

| Field | Authoritative specification |
|---|---|
| Status | **SECONDARY** |
| Input | `gazelle_multispecies_NMix_data.rds`; class order fawn, male, female |
| Framework | `spAbundance::lfMsNMix`, negative binomial, 2 latent factors |
| Abundance formula | `~ Open.Spaces.z + Null.Wolf.Abundance.z * null.jackal.abundance.z` |
| Detection formula | `~ log_days_operational.z + cattle_sightings.z` |
| MCMC | 2,000 batches x 25; burn-in 5,000; thin 10; 3 chains; seed 20260819 |
| Scripts | `fit_focused_multiclass_nmix.R`; `evaluate_focused_multiclass_nmix.R` |
| Saved object | `gazelle_lf2_NMix_NB_open_wolf_jackal_interaction_order-fawn-male-female_2000b_25bl_10th_3ch_fit.rds` |
| Metadata | Matching `_metadata.rds` file records formulas, MCMC settings, seed, and `spAbundance 0.2.1` |
| Tables | `publication_focused_lfmsnmix_class_correlations.csv`; `publication_focused_lfmsnmix_diagnostics.csv`; `publication_focused_lfmsnmix_ppc.csv` |
| Manuscript placement | Three residual correlations in Results, optionally one compact table |
| SI placement | Loadings, all diagnostics, posterior predictive checks, and model comparison |
| Limitations | Use correlations only. Abundance and detection intercepts failed convergence, and ungrouped replicate-level posterior predictive checks indicated lack of fit. Positive correlations are residual association, not causal interaction. |

Two factors are retained because three classes permit at most two free latent dimensions and the two-factor fit captures the residual covariance used for the reported pairwise correlations. This is a modeling choice, not evidence for two ecological mechanisms.

## 9. Gazelle Diel Activity Across Wolf-Jackal Contexts

**Scientific question:** Within each demographic class, do gazelle activity distributions differ among relative wolf-jackal camera contexts?

| Field | Authoritative specification |
|---|---|
| Status | **PRIMARY** |
| Context definition | Median split of site indices: jackal 0.495 and wolf 0.556; all 60 cameras assigned |
| Camera counts | Low both 14; high jackal/low wolf 16; low jackal/high wolf 16; high both 14 |
| Density rule | Do not draw a curve when a class-context group has <5 events |
| Test rule | Formal test requires >=20 events in each context |
| Overlap estimator | `Dhat1` if the smaller sample is <75 events; otherwise `Dhat4` |
| Uncertainty | 500 camera-cluster bootstrap replicates |
| Distribution test | `activity::compareCkern`, 999 null replicates, +1 correction |
| Multiplicity | Benjamini-Hochberg FDR within each class |
| Seeds | 20260810 for the median-context source curves; 20260811 for pairwise overlap/testing |
| Scripts | `make_predator_context_diel_by_class.R`; `analyze_predator_context_diel_pairwise_overlap.R` |
| Table | `publication_authoritative_diel_context_comparisons.csv` |
| Main figure | `publication_predator_context_diel_by_class_median_combined.png` and `.pdf` |
| SI figure | `publication_predator_context_diel_pairwise_overlap_median.png` and `.pdf` |
| Manuscript placement | Primary temporal Methods and Results |
| SI placement | All eligible and descriptive comparisons |
| Limitations | Contexts are observational, median-split site indices. `compareCkern` is event-level; intervals are camera-clustered. The high-jackal/low-wolf fawn group has only 3 events and is data deficient. |

## Reproducibility Gate

All retained models were refitted from corrected inputs and assessed under the documented convergence and model-checking criteria. The package environment is aligned at `glmmTMB 1.1.13` and `TMB 1.9.18`; the study-area map is outside this computational workflow.

Finalization resolved camera 45 deployment chronology while retaining verified malfunction-adjusted effort, corrected camera 22 and 24 clock dates, realigned camera 22 count sessions, and removed seven juvenile detections duplicated into adult event classes. All 344 positive-effort rounds, 5,999 operational camera-days, and 3,925 retained independent events now validate. Early/Late and daylight diel models and the generated map were excluded by final analysis decisions.
