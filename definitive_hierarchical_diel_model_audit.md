# Audit of the definitive hierarchical diel GAMs

This audit uses the saved fits in `definitive_hierarchical_diel_models.rds` and
`definitive_hierarchical_diel_checkpoints_apparent_primary`, generated by
`definitive_hierarchical_diel_GAM.R` on 24 August 2026. No model was refitted or
modified.

## A. Exact model implementation

### Software and fitting

- R 4.5.3 (2026-03-11, UCRT), Windows 11 x64.
- `mgcv` 1.9-4.
- Fitting function: `mgcv::bam()`.
- Smoothing-parameter method: discrete fast REML (`method = "fREML"`,
  `discrete = TRUE`).
- Response family and link: grouped binomial with logit link.
- Shrinkage selection: `select = TRUE`.
- Cyclic knots: `knots = list(Time = c(0, 24))`.
- Threads: `nthreads = 2`.

The exact fitting call stored in every selected model was:

```r
bam(
  formula = formula,
  family = binomial(link = "logit"),
  data = data,
  method = "fREML",
  control = gam.control(trace = FALSE),
  select = TRUE,
  knots = list(Time = c(0, 24)),
  discrete = TRUE,
  nthreads = 2
)
```

`Time` was the midpoint of one of 24 equal-duration apparent-solar-clock bins:
`Time = Time_bin + 0.5`, giving 0.5, 1.5, ..., 23.5 h. Apparent solar time was
calculated as UTC clock time plus longitude/15 and the date-specific
equation-of-time correction. `round_factor` was a seven-level categorical fixed
effect. `camera_id` and `camera_round` were factors.

The population diel curve and all predator-by-time terms used cyclic cubic
regression splines (`bs = "cc"`) with `k = 12`. Parametric predator main effects
were included whenever the corresponding varying-coefficient smooth was
included. In the full model, `wolf_z * jackal_z` expanded to `wolf_z + jackal_z +
wolf_z:jackal_z`, and `wolf_jackal` was the precomputed product
`wolf_z * jackal_z` used as the numeric `by` variable for the interaction smooth.

### Exact selected formulas

**Juvenile: full wolf x jackal structure; camera and camera-round random
intercepts**

```r
cbind(success, failure) ~ round_factor + wolf_z * jackal_z +
  s(Time, bs = "cc", k = 12) +
  s(Time, by = wolf_z, bs = "cc", k = 12) +
  s(Time, by = jackal_z, bs = "cc", k = 12) +
  s(Time, by = wolf_jackal, bs = "cc", k = 12) +
  s(camera_round, bs = "re") +
  s(camera_id, bs = "re")
```

**Adult female: full wolf x jackal structure; camera-specific diel deviations,
camera-round random intercept, and camera random intercept**

```r
cbind(success, failure) ~ round_factor + wolf_z * jackal_z +
  s(Time, bs = "cc", k = 12) +
  s(Time, by = wolf_z, bs = "cc", k = 12) +
  s(Time, by = jackal_z, bs = "cc", k = 12) +
  s(Time, by = wolf_jackal, bs = "cc", k = 12) +
  s(Time, bs = "cc", k = 12, by = camera_id, m = 1, id = 20) +
  s(camera_round, bs = "re") +
  s(camera_id, bs = "re")
```

**Adult male: full wolf x jackal structure; camera-specific diel deviations,
camera-round random intercept, and camera random intercept**

```r
cbind(success, failure) ~ round_factor + wolf_z * jackal_z +
  s(Time, bs = "cc", k = 12) +
  s(Time, by = wolf_z, bs = "cc", k = 12) +
  s(Time, by = jackal_z, bs = "cc", k = 12) +
  s(Time, by = wolf_jackal, bs = "cc", k = 12) +
  s(Time, bs = "cc", k = 12, by = camera_id, m = 1, id = 20) +
  s(camera_round, bs = "re") +
  s(camera_id, bs = "re")
```

**Pooled species: wolf-only structure; camera-specific diel deviations,
camera-round random intercept, and camera random intercept**

```r
cbind(success, failure) ~ round_factor + wolf_z +
  s(Time, bs = "cc", k = 12) +
  s(Time, by = wolf_z, bs = "cc", k = 12) +
  s(Time, bs = "cc", k = 12, by = camera_id, m = 1, id = 20) +
  s(camera_round, bs = "re") +
  s(camera_id, bs = "re")
```

For adult females, adult males, and pooled gazelles, the factor-by-camera
`s(Time, ..., by = camera_id, m = 1, id = 20)` term generated separate cyclic
deviation coefficients for the 60 cameras. The common `id = 20` linked their
penalties so they shared one smoothing parameter.

## B. Model-selection/AIC table

The code used `AIC(fit)` for hierarchy candidates and
`AIC(fit_set[[model_i]])` for ecological candidates. This is `stats::AIC()`
dispatching through `mgcv::logLik.gam`. According to the installed `mgcv` 1.9-4
documentation, this is conditional AIC evaluated at the penalized maximum
likelihood estimates, with effective degrees of freedom and the Wood-Pya-Saefken
correction for smoothing-parameter uncertainty whenever available for REML/fREML
`gam` or `bam` fits. It is therefore reasonable to call it **mgcv corrected
conditional AIC**, but it was not calculated with `cAIC4::cAIC()`.

All ecological candidates were fitted to the same class-specific data with
`bam(method = "fREML", discrete = TRUE)`. The script calculated delta AIC from
the class minimum, retained candidates with delta AIC <= 2, ordered those by
complexity A through E, and selected the least complex remaining candidate.

## C. Final smooth statistics table

The values below come directly from `summary(selected_model)$s.table`. Because
the saved smooth objects have zero-dimensional null spaces and `fit$R` is
available, `summary.gam()` uses `mgcv`'s `reTest` procedure. These are
likelihood-ratio tests with the boundary reference distribution described in
the `summary.gam` documentation. They are not ordinary Wald F tests and are not
simple chi-square tests with `Ref.df` used as a conventional chi-square degree
of freedom. The printed `s.table` nevertheless labels the statistic `Chi.sq`.

For manuscript reporting, use the printed statistic label and retain the
reference-df column, for example: EDF = 2.07, Ref.df = 10, Chi.sq = 21.06,
P < 0.001. State in Methods that P values were the approximate global smooth
tests returned by `summary.gam`, with boundary-reference likelihood-ratio tests
for the zero-null-space smooths.

## D. Any discrepancies between the scripts/output and the manuscript

1. **Primary time scale:** `manuscript_definitive_hierarchical_diel_methods.md`
   still describes `overlap::sunTime()` as the primary response time scale and
   apparent solar time as a sensitivity. The definitive saved models use
   equal-duration apparent solar time as primary; sun time is the sensitivity.

2. **Adult-male selected ecology:** the current Methods file says the additive
   wolf + jackal model was selected for adult males. The final saved model and
   candidate table select the full wolf x jackal structure by 3.262 corrected
   cAIC units over the additive model. The adult-male interaction remains
   sensitivity-dependent, not robust, because the combined sun-time plus
   camera-only sensitivity failed.

3. **Pooled EDF:** the manuscript value EDF = 3.04 belongs to the non-selected
   pooled full interaction model used for robustness testing. The selected
   pooled wolf-only model gives EDF = 3.869643, Ref.df = 10, Chi.sq = 8.040123,
   P = 0.000173. If the manuscript explicitly reports the selected pooled model,
   EDF should be 3.87, not 3.04. If EDF = 3.04 is retained, it must be labeled as
   the primary full-model robustness statistic rather than the selected-model
   statistic.

4. **Sensitivity bookkeeping:** the current Methods file describes five
   sensitivities and the older time-scale direction. The implemented robustness
   rule used seven total specifications: primary apparent-solar full model, k =
   8, k = 16, sun time, alternate hierarchy, apparent-solar independent
   histories, and cached sun time plus alternate hierarchy.

5. **Other focal numerical values:** juvenile interaction EDF = 2.07 and P <
   0.001, juvenile wolf P = 0.059, juvenile jackal P = 0.900, female wolf EDF =
   3.92 and P < 0.001, female jackal P = 0.432, and male interaction EDF = 2.99
   and P < 0.001 all agree with the selected saved model objects.

6. **AIC terminology:** calling the criterion conditional AIC is defensible, but
   the precise description is `mgcv` corrected conditional AIC obtained with
   `stats::AIC()`/`mgcv::logLik.gam`, not `cAIC4::cAIC()`.
